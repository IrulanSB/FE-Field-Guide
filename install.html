Fire Emblem 7

Install on iPhone

This is the address of the live app. Scan the code with your iPhone camera, or type the address into Safari.

Scan this with your iPhone camera. To use a different address, edit the field and tap Make QR.

Steps
  1. Scan the QR code, or type the address into Safari. Chrome on iOS cannot install web apps.
  2. Tap the Share button (square with an arrow).
  3. Scroll down and tap Add to Home Screen.
  4. Name it FE7 and tap Add.
  5. Open it once from the home screen while you have signal, so the offline cache fills.
  6. After that it works in airplane mode.
Progress

Ticks are saved in the browser on that device. Use the run menu → Export to move progress to your PC or another phone, and Import to load it.

If the icon shows a screenshot or a plain page instead of the app, you opened it in a normal tab rather than from the home screen. Delete it and re-add from Safari.
